# Python - Object Relational Mapping

This project connects Python and MySQL using both direct queries with MySQLdb and ORM concepts with SQLAlchemy.

---

## Learning objectives

- Connect Python to MySQL
- Retrieve and insert rows from Python
- Understand ORM principles
- Map Python classes to database tables
- Work with SQLAlchemy models and sessions

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- MySQL 8.0
- MySQLdb 2.0.x
- SQLAlchemy 1.4.x
- `pycodestyle` 2.7.*

---

## Project focus

This project helped me bridge database logic and Python application code through both SQL and ORM approaches.
