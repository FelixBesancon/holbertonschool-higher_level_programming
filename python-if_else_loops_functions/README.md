# Python - if/else, loops, functions

This project focuses on Python control flow, loops, conditions, comments, arithmetic operations, and basic function definitions.

---

## Learning objectives

- Use `if`, `elif`, and `else`
- Write `for` and `while` loops
- Understand indentation and scope
- Create and call functions
- Use comments and return values properly

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.x
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project strengthened my understanding of Python logic and the structure of readable scripts.
