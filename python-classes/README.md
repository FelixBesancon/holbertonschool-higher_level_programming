# Python - Classes and Objects

This project introduces object-oriented programming in Python through classes, objects, attributes, methods, encapsulation, and docstrings.

---

## Learning objectives

- Understand OOP basics
- Create classes and instances
- Use attributes and methods
- Work with `__init__`
- Write class and method documentation

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project gave me a first practical understanding of object-oriented design in Python.
