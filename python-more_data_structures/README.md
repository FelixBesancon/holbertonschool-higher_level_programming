# Python - More Data Structures: Set, Dictionary

This project introduces sets, dictionaries, lambda expressions, and functional tools such as `map`, `filter`, and `reduce`.

---

## Learning objectives

- Use sets and dictionaries
- Iterate through dictionaries and sets
- Understand keys and values
- Work with lambda functions
- Use `map`, `filter`, and `reduce`

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project expanded my knowledge of Python data structures and introduced functional programming concepts.
