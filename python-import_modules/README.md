# Python - Import & Modules

This project introduces Python modules, imports, command-line arguments, and code organization across multiple files.

---

## Learning objectives

- Import functions from another file
- Create and use modules
- Prevent code execution on import
- Use command-line arguments
- Explore objects with `dir()`

---

## Requirements

- Ubuntu 22.04 LTS
- Python 3.10.x
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project helped me understand modular Python code and script execution from the command line.
