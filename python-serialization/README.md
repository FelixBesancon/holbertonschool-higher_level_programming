# Python - Serialization

This project explores serialization and marshaling concepts used for data persistence and communication between systems.

---

## Learning objectives

- Understand serialization vs marshaling
- Convert objects into transferable formats
- Work with JSON, XML, or binary representations
- Understand practical data persistence use cases

---

## Requirements

- Python 3
- Executable files
- Clean and structured code

---

## Project focus

This project introduced practical techniques for saving, transmitting, and reconstructing structured data.
