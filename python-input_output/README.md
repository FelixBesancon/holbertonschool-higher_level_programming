# Python - Input/Output

This project focuses on file handling, reading and writing text files, JSON serialization, and command-line parameter usage.

---

## Learning objectives

- Open and close files properly
- Read files line by line
- Write text to files
- Serialize and deserialize JSON
- Use `with` statements safely

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*
- Tests stored in `tests/`

---

## Project focus

This project helped me handle persistent data and file-based workflows in Python.
