# JavaScript - Warm Up

This project introduces JavaScript scripting fundamentals through variables, conditions, loops, functions, objects, arrays, and modules.

---

## Learning objectives

- Run JavaScript scripts with Node.js
- Use variables and constants
- Write conditions and loops
- Create functions
- Manipulate objects and arrays
- Import files and modules

---

## Requirements

- Ubuntu 20.04 LTS
- Node.js 14.x
- Executable files
- `semistandard` 16.x.x

---

## Project focus

This project gave me my first practical foundations in JavaScript scripting and syntax.
