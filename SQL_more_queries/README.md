# SQL - More Queries

This project expands on SQL with joins, unions, permissions, users, keys, constraints, and relational modeling concepts.

---

## Learning objectives

- Create users and manage privileges
- Use primary and foreign keys
- Write joins and subqueries
- Understand constraints and normalization basics

---

## Requirements

- Ubuntu 20.04 LTS
- MySQL 8.0
- SQL files with comments
- Uppercase SQL keywords

---

## Project focus

This project strengthened my ability to write more advanced relational queries and work with structured databases.
