# Python - Exceptions

This project focuses on Python error handling and the correct use of exceptions in scripts and functions.

---

## Learning objectives

- Understand errors vs exceptions
- Catch exceptions properly
- Raise built-in exceptions
- Use cleanup actions when needed
- Write safer Python code

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project helped me write more robust code by handling invalid input and runtime errors safely.
