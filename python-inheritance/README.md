# Python - Inheritance

This project focuses on inheritance, subclassing, method overriding, and the use of built-in type-checking helpers.

---

## Learning objectives

- Understand parent and child classes
- Use inheritance in Python
- Override inherited methods
- Work with `isinstance`, `issubclass`, `type`, and `super`

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*
- Tests stored in `tests/`

---

## Project focus

This project taught me how code reuse and hierarchy work in object-oriented Python.
