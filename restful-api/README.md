# RESTful API

This project introduces the fundamentals of REST architecture, HTTP/HTTPS, API consumption, API development, authentication, and documentation.

---

## Learning objectives

- Understand REST principles
- Consume APIs with command-line tools and Python
- Build APIs with `http.server` and Flask
- Learn API security basics
- Explore OpenAPI documentation concepts

---

## Requirements

- Python 3.9
- Flask for some tasks
- Executable scripts

---

## Project focus

This project gave me a first practical understanding of backend communication and API design.
