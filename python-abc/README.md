# Python - Abstract Classes and Interfaces

This project introduces abstract base classes, interfaces, duck typing, subclassing, and method overriding in Python.

---

## Learning objectives

- Use abstract classes
- Understand interfaces and duck typing
- Override inherited methods
- Extend standard base classes
- Work with multiple inheritance and mixins

---

## Requirements

- Python 3
- Executable files
- Clean and readable OOP code

---

## Project focus

This project strengthened my understanding of advanced object-oriented design patterns in Python.
