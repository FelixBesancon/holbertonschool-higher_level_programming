# Python - More Classes and Objects

This project continues Python OOP with class attributes, static methods, class methods, `__str__`, `__repr__`, and deeper class behavior.

---

## Learning objectives

- Distinguish instance and class attributes
- Use class methods and static methods
- Implement `__str__` and `__repr__`
- Improve encapsulation and class design

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project helped me deepen my understanding of object design and Pythonic class patterns.
