# Python - Data Structures: Lists, Tuples

This project explores Python lists, tuples, sequences, list methods, comprehensions, and data manipulation basics.

---

## Learning objectives

- Use lists and tuples
- Understand list methods
- Compare strings and lists
- Use list comprehensions
- Understand packing and unpacking

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*

---

## Project focus

This project developed my understanding of Python collections and common sequence operations.
