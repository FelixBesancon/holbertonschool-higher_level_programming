# Python - Test Driven Development

This project introduces test-driven development through documentation, doctests, edge cases, and function-first thinking.

---

## Learning objectives

- Write tests before implementation
- Use doctests
- Write meaningful docstrings
- Identify edge cases
- Document modules and functions clearly

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- Executable files
- `pycodestyle` 2.7.*
- Tests stored in `tests/`

---

## Project focus

This project taught me to think more rigorously about inputs, outputs, and expected behavior before coding.
