# SQL - Introduction

This project introduces relational databases and SQL through basic queries, table creation, data manipulation, and MySQL fundamentals.

---

## Learning objectives

- Understand relational databases
- Create and alter tables
- Select, insert, update, and delete data
- Use SQL functions and subqueries

---

## Requirements

- Ubuntu 22.04 LTS
- MySQL 8.0
- SQL files with task comments
- Uppercase SQL keywords

---

## Project focus

This project helped me build strong foundations in SQL syntax and relational database usage.
